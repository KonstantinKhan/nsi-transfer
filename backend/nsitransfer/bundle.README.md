# Бандл для развертывания NsiTransfer

Этот пакет содержит все необходимое для запуска приложения NsiTransfer с помощью Docker.

## Требования
- Docker
- Docker Compose

## Как запустить
1. Распакуйте этот архив на целевой машине.
2. Откройте терминал (PowerShell) в этой папке.
3. Выполните команду: `.\run.ps1`
