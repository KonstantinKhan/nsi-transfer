## Точка входа

- точка входа в `wiki` находится в папке `**/wiki/` в файле `index.md`

## Правила использования

- В `index.md` нужно найти подходящую информацию и пройти по wiki-ссылке к соответсвующей заметке, изучить её и использовать для решения задачи
- Если подходящей информации нет - об этом нужно явно сообщить пользователю
- Допускается ходить по перекрёстным ссылкам, если требуемая для решения информация находится в разных заметках
- STRICT! Запрещается читать всё подряд на всякий случай - только точный и обоснованный поиск и использование информации
