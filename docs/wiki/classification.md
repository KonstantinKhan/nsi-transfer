# Классификация объектов

Система автоматического присвоения кодов классификатора объектам на основе их принадлежности к родительским группам.

## Концепция

Каждый объект в Полиноме может находиться в одной или нескольких группах классификации. Коды классификатора присваиваются объектам в соответствии с иерархией группировок.

**Данные хранятся в концепции:** "Данные классификатора"

**Свойство для хранения кода:** "Код классификатора"

## Процесс обработки

### 1. Инициирование процесса

Эндпоинт: `POST /api/polynom-sync/start-data-collection-in-background`

Запускает фоновый процесс синхронизации, который:
1. Собирает изменённые объекты за период
2. Для каждого объекта обрабатывает код классификатора
3. Публикует результаты в RabbitMQ

### 2. Основной процессор

**Класс:** `ClassificationCodeProcessor` (`NsiTransfer.BLL/Services/ClassificationCodeProcessor.cs`)

**Метод:** `ProcessAsync()`

```
1. Получить свойство "Код классификатора" у объекта
2. Если код есть → сохранить и выход
3. Если кода нет → получить родительские группы
4. Определить "корректную" родительскую группу
5. Вычислить новый код на основе максимального кода в группе
6. Установить код объекту через API
```

### 3. Вычисление кода

**Алгоритм:**

```
1. Получить все дочерние узлы родительской группы
2. Для каждого дочернего узла:
   - Получить его свойства
   - Найти значение "Код классификатора"
   - Проверить, что код входит в диапазон [min, max] группы — иначе пропустить
     как ошибочные данные (не учитывать при поиске максимума)
   - Сравнить с текущим максимальным (используя NumericStringComparer)
3. Вернуть максимальный код + 1
```

**Пример:**
- Родительская группа содержит объекты с кодами: 001, 002, 003
- Новому объекту присваивается код: 004

**Пример с ошибочными данными:**
- Диапазон группы: [001, 999]
- Среди детей есть объект с кодом 1500 (ошибочные данные, вне диапазона) и объект с кодом 010
- Код 1500 игнорируется при поиске максимума → новому объекту присваивается 011, а не 1501

### 4. Установка кода

**Метод:** `UpdateClassificationCodeAsync()` → `SetPropertyValues`

Отправляет на эндпоинт `/api/v1/property-owner/set-property-values` запрос:

```json
{
  "Owner": { "ObjectId": 123, "TypeId": 45 },
  "Properties": [
    {
      "Contract": { "ObjectId": 789, "TypeId": 67 },
      "Definition": { "ObjectId": 456, "TypeId": 78 },
      "Value": "004"
    }
  ]
}
```

## Обработка ошибок

**Типы ошибок:** `PolynomObjectFailureTypeEnum`

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `CannotFindPropertyClassificationCode` | Свойство "Код классификатора" не найдено | Проверить конфигурацию `ClassificationCodePropertyName` |
| `NoGroupsAtAll` | У объекта нет родительских групп | Объект не входит ни в какую группу |
| `MultipleGroupsWithMinMax` | Несколько групп с необходимыми свойствами | Нельзя выбрать одну группу для кода |
| `ErrorWhileProcessWasExecuting` | Ошибка API Полинома | Проверить логи и подключение к API |

## Конфигурация

**Файл:** `configuration.json`

```json
"PolynomApiSyncOptions": {
  "ConceptNameForClassificationData": "Данные классификатора",
  "ClassificationCodePropertyName": "Код классификатора",
  "OwnContractName": "Собственные свойства",
  "MinCodePropertyName": "Минимальное значение кода",
  "MaxCodePropertyName": "Максимальное значение кода"
}
```
