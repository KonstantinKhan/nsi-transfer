# История: Очистка кредов и переписание коммитов

**Дата:** 2026-09-21  
**Статус:** ✅ Завершено

## Проблема

Креденшалы (пароли, токены) попали в ранние коммиты репо. Необходимо удалить их из истории.

## Решение

1. **Локальная переписание истории**
   - Все 18 коммитов в ветке переписаны в один
   - Версия без кредов
   - Коммит: `4c0947a All fixes and configurations`

2. **Синхронизация веток**
   - `main` и `bug-fix-21-09-26` объединены
   - Обе ветки указывают на один чистый коммит
   - Force push выполнен

3. **Удаление лишних веток**
   - Локально удалены: `backup-bug-fix-21-09-26`, `bug-fix-21-09-26`
   - На GitHub удалена: `origin/bug-fix-21-09-26`
   - Осталась только `main`

## На других машинах

```bash
git fetch origin
git branch -d backup-bug-fix-21-09-26 2>/dev/null || true
git branch -d bug-fix-21-09-26 2>/dev/null || true
git reset --hard origin/main
git branch | grep -v "main" | xargs git branch -D  # удалить остальные локальные ветки
git remote prune origin
```

## Результат

- ✅ Креды удалены из истории
- ✅ История переписана (1 коммит вместо 18)
- ✅ Все машины синхронизированы
- ✅ Только main ветка осталась в репо

## Wichtig

GitHub хранит удалённые коммиты ограниченное время (для восстановления в случае ошибки). Креды всё ещё видны в кеше, поэтому **ротировать все креденшалы** на сервисах (БД, API, etc).
